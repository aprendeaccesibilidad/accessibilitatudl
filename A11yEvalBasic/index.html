Pensada para aprender y enseñar accesibilidad

Inspirada en W3C WAI Easy Checks

La herramienta toma como punto de partida la propuesta Easy Checks, una guía para realizar primeras comprobaciones de accesibilidad. A11yEvalBasic adapta ese enfoque a una experiencia visual e interactiva sobre la propia página web.

Qué es y qué no es

A11yEvalBasic no certifica conformidad WCAG ni sustituye una auditoría experta. Ayuda a realizar una primera observación guiada y educativa.

Estudiantes

Para practicar la detección de barreras en ejercicios, proyectos y páginas web reales.

Docentes

Para explicar criterios básicos de accesibilidad con ejemplos visibles durante una clase o actividad.

Diseño y desarrollo web

Para iniciar una revisión básica antes de abordar una evaluación más completa.

Una herramienta para observar, activar y aprender

El objetivo no es ofrecer una certificación automática, sino facilitar una primera mirada educativa sobre barreras habituales de accesibilidad.

Cómo funciona

A11yEvalBasic se instala como un marcador del navegador. Después se activa sobre la página que quieres revisar.

  1. Añade el bookmarklet a la barra de marcadores.
  2. Abre la página web que quieres observar.
  3. Activa A11yEvalBasic desde tus marcadores.
  4. Elige una discapacidad o un grupo de comprobaciones.
  5. Activa una opción y observa las marcas en la página.

Preguntas frecuentes

¿La herramienta sustituye una auditoría de accesibilidad?

No. Es una herramienta educativa para una primera observación guiada. No certifica conformidad WCAG ni sustituye una revisión experta.

¿Funciona como una extensión del navegador?

No exactamente. Funciona como bookmarklet: un marcador que carga el panel de evaluación sobre la página que estás visitando.

¿Qué necesito para usarla?

Un navegador con barra de marcadores y una página web abierta. La herramienta carga el script desde el servidor local en https://accessibilitat.udl.cat/A11yEvalBasic/.

¿Por qué las comprobaciones se organizan por discapacidad?

Para facilitar el aprendizaje desde distintas experiencias de uso y conectar cada barrera con las personas a las que puede afectar.
